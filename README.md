## 📖 Overview

Unraveling hierarchical structure–property relationships is central to materials science, requiring interpretation of data across physical scales from atomic to macro. While Large Multimodal Models (LMMs) are increasingly used in scientific workflows, existing benchmarks focus on general chart reading or isolated reasoning and do not evaluate **cross-scale perception** on real materials figures.

**CSMBench** is a benchmark of **1,041** high-quality figures from premier materials journals (through September 2025), organized into four scientifically distinct regimes: **AtomScale**, **Microscale**, **Mesoscale**, and **Macroscale**. It supports two evaluation tasks:

| Task | Description | Metric |
|------|-------------|--------|
| **OpenQA** | Open-ended figure description given caption | LLM judge score (0–10) |
| **MCQA** | Multiple-choice caption matching | Accuracy |

## ✨ Key Features

- **1,041 expert-curated figures** spanning atomic, micro, meso, and macro scales.
- Two tasks aligned with real materials-science workflows: description and caption matching.
- Systematic evaluation of open-source and closed-source LMMs across physical scales.
- Public release on Hugging Face with reproducible evaluation scripts.

## 📁 Repository Structure

```text
CSMBench/
├── CSMBench_Data/              # download from Hugging Face (not in repo)
│   ├── multi_scale.json        # generated by prepare_dataset.py
│   └── multi_scale_mcq.json
├── examples/                   # small sample for quick testing
│   ├── data/
│   └── figures/
└── src/
    ├── openqa_generate.py      # Task 1: open-ended generation
    ├── mcqa_generate.py        # Task 2: multiple-choice inference
    ├── score_openqa.py         # Task 1: LLM judge scoring
    ├── score_mcqa.py           # Task 2: accuracy by scale
    ├── prepare_dataset.py      # convert HF download to JSON
    └── utils.py
```

## 🗃️ Dataset Access

The full dataset is available on [🤗 CSMBench (lututu/CSMBench)](https://huggingface.co/datasets/lututu/CSMBench).

Configs:

- **multi_scale** — open-ended description (caption + reference paragraph)
- **multi_scale_mcq** — four-option caption matching

## 🚀 Quick Start

### 1. Clone the Repository

```bash
git clone https://github.com/zhengyt058/CSMBench.git
cd CSMBench
```

### 2. Install Dependencies

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 3. Download the Dataset

```bash
pip install huggingface_hub

huggingface-cli download \
    --repo-type dataset \
    --resume-download \
    lututu/CSMBench \
    --local-dir CSMBench_Data
```

Convert the ImageFolder layout to JSON files used by the evaluation scripts:

```bash
cd src
python prepare_dataset.py --data-dir ../CSMBench_Data
```

### 4. Configure API Access

Evaluation uses OpenAI-compatible vision APIs. Set your credentials:

```bash
export OPENAI_API_KEY="your-api-key"
# Optional: custom endpoint
export OPENAI_BASE_URL="https://api.openai.com/v1"
```

### 5. Run Evaluation

#### Task 1: Open-ended Figure Description

```bash
cd src

python openqa_generate.py \
    --input ../CSMBench_Data/multi_scale.json \
    --output-dir ../outputs/openqa \
    --data-root .. \
    --model gpt-4o

python score_openqa.py ../outputs/openqa/gpt-4o_openqa_output.json \
    --reference ../CSMBench_Data/multi_scale.json
```

#### Task 2: Multiple-Choice Caption Matching

```bash
python mcqa_generate.py \
    --input ../CSMBench_Data/multi_scale_mcq.json \
    --output-dir ../outputs/mcqa \
    --data-root .. \
    --model gpt-4o

python score_mcqa.py \
    --input ../outputs/mcqa/gpt-4o_mcqa_output.json
```

### 6. Try with Example Data (no full download)

A small subset (4 scales × 1 sample) is included under `examples/`:

```bash
cd src

python openqa_generate.py \
    --input ../examples/data/multi_scale_sample.json \
    --data-root .. \
    --model gpt-4o

python mcqa_generate.py \
    --input ../examples/data/multi_scale_mcq_sample.json \
    --data-root .. \
    --model gpt-4o
```
